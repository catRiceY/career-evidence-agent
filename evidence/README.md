# Public evidence bundle

This directory contains only reviewed evidence that is approved for public use.

- `registry/approved/` contains canonical Evidence, Claim and Source records
  consumed by the API and evaluation suite.
- `reviews/` contains the public-safe human decisions that define attribution
  and disclosure boundaries for those records.

Private sources, unpublished research material and personal job-preparation
records are deliberately excluded. Adding a file here does not make it public
evidence automatically: a canonical record must explicitly be approved and its
claims must cite public sources.
